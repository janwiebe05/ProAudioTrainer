## Tips

- Use 1280×800 or similar for consistency
- GIFs should be under 5MB (use [Gifski](https://gif.ski/) or [LICEcap](https://www.cockos.com/licecap/))
- Show real content — placeholder data is fine, but audio waveforms and frequency displays should be visible
